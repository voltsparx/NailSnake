# Usage

Run NailSnake from an interactive terminal:

```bash
nailsnake
```

Useful options:

```bash
nailsnake --difficulty hard --wrap --grid
nailsnake --color truecolor
nailsnake --about
nailsnake --help
nailsnake --version
```

Controls:

| Key | Action |
| --- | --- |
| Arrow keys | Move by default |
| W/A/S/D | Alternate movement |
| Space or Enter | Pause or resume |
| R | Restart |
| Q or Esc | Quit |
| Ctrl+C | Force quit and save an active game |

The main menu shows Continue when a valid saved game exists. Continue resumes
the saved board in a paused state so the player can re-enter safely.

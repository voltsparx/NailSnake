Speciality

Terminal-first, not terminal-limited.

Rust-themed TUI

Dark copper tones, red food, clean borders, and a fast keyboard-driven interface.

Classic mechanics

Arcade Snake movement, pause menu, wrap option, difficulty presets, and progressive speed.

Continue recovery

Active sessions are saved separately so forced quits can be resumed safely later.

Cross-platform installers

Release packaging targets Linux formats, Termux, macOS CLI packages, and Windows installs.

Inspiration

Inspired by nsnake, rebuilt for Rust.

NailSnake keeps the familiar terminal Snake rhythm while adding a Rust-flavored presentation, safer terminal cleanup, user settings, skin selection, and modern packaging for real CLI distribution.
